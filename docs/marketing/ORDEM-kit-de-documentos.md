o sistema de combo. O Rodrigo achou o resultado péssimo. **Nenhuma sessão monta documento de
cabeça de novo:** monta a partir deste kit.


Logo de marca e fonte OFL podem ir para o repositório público. **Documento com dado de pessoa
ou salário não vai:** o kit é só o modelo vazio.

A `FICHA-DOCUMENTOS.md` traz, para cada uma das três peles, os números que hoje ninguém tem:

| Item | O que registrar |
|---|---|
| Cores | hex oficiais: fundo, acento, texto, tabela, destaque |
| Fontes | família e peso de título, subtítulo, corpo, tabela e rodapé |
| **Tamanhos** | em pt: título, subtítulo, corpo, tabela, legenda e rodapé |
| Logo | qual versão em cada fundo, tamanho mínimo, área de respiro e posição |
| Página | A4, margens, cabeçalho e rodapé (SEM HORA MARCADA, endereço ou telefone) |
| Tabelas | cabeçalho, zebra, linha de total e destaque |
| Consolidado | como as duas marcas convivem na mesma página (do vault `15_`) |

## Prova de que funcionou

1. Gerar o `exemplo.pdf` de cada pele e **mostrar ao Rodrigo antes de virar padrão**.
2. Depois do aval, refazer no modelo **consolidado** a *Proposta de Gerente das Unidades*. O
   conteúdo fica com a sessão que fez a proposta, e só a pele muda. Salvar no OneDrive, **não** no repositório.
3. Atualizar `docs/marketing/identidade-visual.md` e o vault com o que foi corrigido.
